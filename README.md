# Madara Uchiha - Wake Up to Reality

A simple Python Flask web application inspired by Madara Uchiha's
famous "Wake Up to Reality" speech.

## Technologies

- Python
- Flask
- Docker
- HTML/CSS

## Run with Docker

```bash
docker build -t madara-reality-app .
docker run -d -p 5000:5000 --name madara-app madara-reality-app
